Output: Zero-copy chunk pipeline providing a continuous `Read + Seek` byte stream to the audio decoder.

<task type="auto">
  <name>Implement Chunk Downloader with Range Requests</name>
  <action>Implement `crates/bitchord-core/src/stream/downloader.rs`. Support configurable chunk sizes (default 512KB - 1MB) using HTTP `Range: bytes=start-end` headers. Use `bytes::Bytes` to prevent redundant copies. Pre-fetch upcoming chunks asynchronously ahead of the playback cursor.</action>
  <verification>Unit test verifying chunk range splitting and HTTP request composition.</verification>
</task>

<task type="auto">
  <name>Implement 403 Forbidden Auto-Recovery & Stream Renewal</name>
  <action>Handle 403 Forbidden errors encountered at chunk boundaries (e.g., at 1MB / block 4). When 403 occurs: pause chunk ingestion, fetch a renewed player stream URL from Innertube with fresh expiration/signature parameters, and retry with randomized exponential backoff (up to 6 retries). Never bubble up 403 errors to the audio playback layer.</action>
  <verification>Test mock 403 error recovery simulating URL renewal and stream resumption.</verification>
</task>

<task type="auto">
  <name>Implement Hybrid Stream Buffer (Memory + Temp Cache)</name>
  <action>Implement `crates/bitchord-core/src/stream/buffer.rs` and `crates/bitchord-core/src/cache/disk.rs`. Keep the current playing window in a compact in-memory byte buffer for instant zero-latency seeks within buffered regions. Asynchronously append chunks to a temporary file in `%TEMP%/bitchord_cache` with an LRU eviction policy (capped at 500MB total disk use). Implement `std::io::Read` and `std::io::Seek` over the hybrid buffer.</action>
  <verification>Unit test asserting Read + Seek operations across chunk boundaries and verifying disk eviction.</verification>
</task>
