## Phase Boundary

Bootstrap the desktop GUI application in `crates/bitchord-tauri` using Tauri v2, Vite, React, TypeScript, and Tailwind CSS. Wire the Tauri IPC commands directly to `bitchord-core::AudioEngine` and deliver a frameless Windows window with an Apple Music-inspired liquid glass aesthetic, search feed, and responsive now-playing capsule.

<decisions>
## Implementation Decisions

### 1. Frontend Technology Stack
- **Decision:** React 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons.
- **Rationale:** Ultra-fast HMR in development, tiny bundle size (< 2MB web assets), rich CSS backdrop-blur and glassmorphism support.
- **Reversibility:** costly — changing UI framework requires re-implementing components.

### 2. Window Framing & Materials
- **Decision:** Custom frameless window with `window-vibrancy` (Mica / Acrylic on Windows 11) and custom draggable header controls (minimize, maximize, close).
- **Rationale:** Recreates the modern native look of Apple Music / BitChord without generic OS window chrome.
- **Reversibility:** reversible — window configuration is controlled in `tauri.conf.json`.

### 3. IPC Architecture & State Synchronization
- **Decision:** Bidirectional Tauri IPC:
  - Frontend invokes async commands (`play_track`, `toggle_pause`, `seek_to`, `set_volume`, `search_music`).
  - Backend emits lightweight tick events (`bitchord://progress { pos_ms, dur_ms, is_playing }`) at 10Hz (100ms interval) to drive smooth 60fps UI scrubbers without polling overhead.
- **Rationale:** Minimizes IPC message bandwidth while ensuring instant UI reactivity.
- **Reversibility:** reversible — event payloads are typed with serde.

### 4. Liquid Glass Aesthetic Tokens
- **Palette:** Dark glass background (`rgba(18, 18, 22, 0.75)`), floating pill backdrop blur (`backdrop-blur-xl border border-white/10 shadow-2xl`), accent glow dynamically derived from album artwork.
- **Typography:** SF Pro Display / Inter clean typographic hierarchy.

</decisions>
